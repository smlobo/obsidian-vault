1. **Define the symptom:** correctness, crash, hang, or performance.
2. **Establish scope:** one host, tenant, node, protocol, or entire cluster.
3. **Build a timeline:** when did it begin, and what changed?
4. **Preserve evidence:** logs, metrics, traces, core dumps, configuration.
5. **Localize by layer:** application → OS → network → target → media.
6. **Compare:** healthy versus unhealthy node or workload.
7. **Form ranked hypotheses.**
8. **Run discriminating tests**, changing one variable at a time.
9. **Mitigate safely**, then find root cause.
10. **Prevent recurrence:** test, invariant, telemetry, or design change.
