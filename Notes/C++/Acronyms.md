* RAII : Resource Allocation Is Initialization
* CTAD : Class Template Argument Deduction
* ODR : One Definition Rule
* cv-qualifier : `const` or `volatile` qualifier
* Top-Level qualifier : applies to the variable itself
* Low-Level qualifier : applies to the data being pointed to
* CRTP : Curiously Recurring Template Pattern
* COW : Copy On Write
	* Not allowed anymore; MT env
* RVO : Return Value Optimization
	* creates return values on the caller stack
