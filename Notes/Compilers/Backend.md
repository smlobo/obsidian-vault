| Optimization                       | Before → after                                                                            | Why it helps                                                                                    |
| ---------------------------------- | ----------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| **Instruction combining**          | `multiply i by 4; add base` → one indexed-address instruction such as `load [base + i*4]` | Uses the target’s addressing modes.                                                             |
| **Strength reduction**             | `x * 8` → `x << 3`                                                                        | Replaces an operation with a potentially cheaper one. This is not always faster on modern CPUs. |
| **Peephole optimization**          | `move r1, r2; move r2, r1` → remove or simplify the redundant moves                       | Cleans up short instruction sequences after other passes.                                       |
| **Dead instruction elimination**   | `r1 = add a, b; r1 = 0` → `r1 = 0`                                                        | Removes a result that is overwritten before use.                                                |
| **Copy coalescing**                | `r2 = r1; use r2` → assign `r1` and `r2` the same physical register                       | Eliminates a move during register allocation.                                                   |
| **Rematerialization**              | Spill a constant to memory, then reload it → recreate the constant when needed            | Can be cheaper than a stack load.                                                               |
| **Spill reduction**                | Keep a frequently used value in a register and spill a rarely used one                    | Reduces memory traffic when registers are scarce.                                               |
| **Instruction scheduling**         | `load a; use a; independent add` → `load a; independent add; use a`                       | Gives the load more time to complete before its result is needed.                               |
| **Branch folding**                 | `if condition jump A; jump B` → invert the condition and let one path fall through        | Removes an unconditional jump.                                                                  |
| **Basic block placement**          | Put the frequently executed successor immediately after its predecessor                   | Improves fall-through behavior and often instruction-cache use.                                 |
| **Tail duplication**               | Copy a small shared block into its predecessors                                           | Can remove jumps and create better scheduling opportunities, at the cost of code size.          |
| **If-conversion**                  | Short branch assigning `0` or `1` → conditional move or select                            | May avoid a hard-to-predict branch. It can be worse if both paths do expensive work.            |
| **Load/store forwarding**          | `store x to [p]; load [p] into y` → `y = x`                                               | Avoids a load when the compiler can prove no intervening write changed `[p]`.                   |
| **Vectorization or SIMD lowering** | Four scalar additions → one vector addition                                               | Processes multiple values per instruction when alignment and semantics permit.                  |
| **Tail-call optimization**         | `return f(x)` → jump to `f` after preparing its arguments                                 | Reuses the current stack frame when calling-convention rules allow it.                          |
| **Shrink wrapping**                | Save a callee-saved register at function entry → save it only on paths that use it        | Reduces work on paths that do not need the register.                                            |
